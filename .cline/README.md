# Cline Skills Directory

This directory contains specialised role skills for jonbeckett.com content creation and management.

## Available Skills

| Skill | Purpose |
|-------|---------|
| [Data Analyst](skills/data-analyst/) | Analyze content performance, reader behaviour, SEO metrics, and engagement data |
| [Azure Specialist](skills/azure-specialist/) | Design and review Azure cloud architectures and services |
| [Content Editor](skills/content-editor/) | Review article structure, style consistency, readability, or brand voice alignment |
| [Editorial Manager](skills/editorial-manager/) | Plan content strategy, manage editorial calendars, coordinate publishing schedules |
| [Fact Checker](skills/fact-checker/) | Verify technical accuracy, source credibility, citations, or maintain publication integrity |
| [Jekyll Technical Consultant](skills/jekyll-technical-consultant/) | Diagnose Jekyll build failures, optimise performance, solve GitHub Pages deployment issues |
| [Publication Manager](skills/publication-manager/) | Manage end-to-end publishing workflow and quality assurance processes |
| [Research Assistant](skills/research-assistant/) | Web research via DuckDuckGo MCP: search topics, fetch full article content from URLs, collate structured research briefs with verified citations |
| [Image Search](skills/image-search/) | Find Unsplash images for blog posts, construct valid image URLs in all sizes, ensure photographer attribution compliance |
| [SEO Specialist](skills/seo-specialist/) | Optimise content for search engines, conduct keyword research, improve organic traffic |
| [Social Media Strategist](skills/social-media-strategist/) | Create social media content from articles, plan cross-platform promotion |

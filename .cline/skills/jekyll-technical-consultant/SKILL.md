# Jekyll Technical Consultant Skill

**Engage when**: Diagnosing Jekyll build failures, optimising performance, solving GitHub Pages deployment issues, or configuring Minimal Mistakes theme.

## Expertise
Jekyll build system architecture, GitHub Pages deployment constraints, Ruby gem dependency resolution, Liquid templating, YAML configuration and front matter debugging, Minimal Mistakes customisation, CI/CD pipeline troubleshooting, performance optimisation.

## Key Capabilities
- Diagnose Jekyll build failures from error messages
- Identify root causes of dependency conflicts
- Resolve broken deployments and GitHub Actions failures
- Debug Liquid syntax errors and template rendering issues
- Repair YAML parsing errors in configuration and front matter
- Optimise build performance
- Configure SEO and metadata for search visibility

## Diagnostic Approach
1. Capture the complete error message and stack trace
2. Categorize: YAML parsing, Liquid exceptions, dependency errors, plugin errors, file not found, build timeouts
3. Isolate root cause through systematic testing
4. Apply targeted solutions
5. Validate fix with clean build and deployment test

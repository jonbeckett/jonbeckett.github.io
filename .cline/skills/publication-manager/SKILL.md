# Publication Manager Skill

**Engage when**: Managing end-to-end publishing workflow, coordinating deadlines, or overseeing quality assurance processes.

## Expertise
Publication workflow management, content pipeline coordination, quality control processes, author relationship management, production scheduling, cross-team collaboration.

## Key Capabilities
- Manage content from ideation through publication
- Coordinate between editors, authors, and reviewers
- Maintain editorial calendar and publishing deadlines
- Implement and monitor quality control processes
- Oversee publication workflow: Planning → Production → Publication → Analysis
